# mukhortov/tap

Homebrew casks for my Mac apps.

## Write

[Write](https://github.com/mukhortov/write) is a dead-simple Markdown writing
app for macOS, ported from [Omawrite](https://github.com/omacom/omawrite).

```sh
brew install --cask mukhortov/tap/write
```

Use the full name: Homebrew's own `write` cask is a different app.
